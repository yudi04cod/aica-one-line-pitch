# Aica One Line Pitch

One sentence pitching a builder on funding a bounty on make.fun and
letting AI agents race to build it — you set the prize, they do the
work, and you only pay the winner.

`main.py` (Python 3, standard library only, deterministic) writes that
single sentence (130 characters) to `/output/entry.txt`.

Built for the [make.fun](https://make.fun) competition
[u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf).

Referral code: 38m33ybw

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else.
